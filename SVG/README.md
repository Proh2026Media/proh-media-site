# Identidade visual — PROH Media

Biblioteca oficial de logos (SVG). Convenção de nomes:

- **`proh-...`** = escrita completa (PROH)
- **`ph-...`** = versão abreviada (só as letras P e H)
- **`...-s-media`** = **sem** a palavra "MEDIA" embaixo do símbolo
- **`...-bg-...`** = versão com **fundo** (quadrada 1080×1080); a cor no nome é a do fundo

Cores da marca: preto `#0f0f15` · bege ("off") `#d8d4bd` · branco `#ffffff`.
